Northlight Sample: a block theme (theme.json, templates, patterns using core blocks only) for a fictional physio landing page, fully editable in the Site Editor.
Install: Appearance > Themes > Add New > Upload Theme > northlight-sample.zip > Activate (front page uses templates/front-page.html).
Tested on WordPress 7.1.5 with PHP 8.3.6 (SQLite, local); screenshots front-375.png and front-1280.png.
